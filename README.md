# 📊 Django CRM Web Application

A full-featured Customer Relationship Management (CRM) web application built with **Python** and **Django**. This project allows users to authenticate, manage client records, search, and handle record creation, updates, and deletion efficiently.

---

## 🚀 Live Demo

You can try the live application hosted on PythonAnywhere here:  
👉 **[Live Demo](https://mahmoudmaher.pythonanywhere.com)**

---

## ✨ Features

* **User Authentication:** User registration, login, and logout capabilities.
* **Record Management (CRUD):** Create, View, Update, and Delete customer records.
* **Dynamic Search:** Search through client records seamlessly using Django `Q` objects.
* **Interactive UI:** Clean user interface powered by Bootstrap with auto-dismissing flash messages for actions and notifications.
* **Database Management:** Uses SQLite database for managing application data.

---

## 🛠️ Tech Stack

* **Backend:** Python 3.12, Django
* **Frontend:** HTML5, CSS3, Bootstrap
* **Database:** SQLite
* **Deployment:** PythonAnywhere
